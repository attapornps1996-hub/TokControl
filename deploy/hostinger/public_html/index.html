Features

ทุกอย่างที่สตรีมเมอร์ต้องใช้

ออกแบบมาเพื่อไลฟ์ TikTok โดยเฉพาะ — ติดตั้งครั้งเดียวใช้ได้ครบทุกระบบ

🎰

ระบบสุ่มและกาชา

วงล้อเสี่ยงโชคและตู้กาชาพร้อมอนิเมชันเปิดการ์ด ตั้งรางวัลและอัตราออกเองได้ หมุนอัตโนมัติเมื่อได้รับของขวัญตามที่กำหนด

🎁

เอฟเฟกต์ Reaction

Gift Firework, Gift Cannon, น้ำพุหัวใจ และกำแพงอีโมจิ ตอบสนองทันทีที่ผู้ชมส่งของขวัญหรือกดไลค์ พร้อมเสียงประกอบ

🖼️

Widget สำหรับ OBS

คัดลอกลิงก์ไปวางใน Browser Source ของ OBS หรือ TikTok Studio ได้ทันที รองรับทั้งจอแนวนอน 16:9 และแนวตั้ง 9:16

📊

สถิติและอันดับสด

Leaderboard ผู้ให้ของขวัญ แถบเป้าหมายไลค์และเหรียญ พร้อมระบบแต้มช่องจำลองสำหรับแลกรางวัลกับผู้ชม
